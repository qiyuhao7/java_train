# 第01期：开发必备命令行（Linux & Git）

## 实战内容

### git-exercises/ — IDEA 操作 Git 实操手册
按照手册在 IntelliJ IDEA 中完成：克隆、提交推送、分支、冲突解决、stash、历史回退等操作。
详见 `git-exercises/README.md`

### scripts/ — Linux 常用命令实操

| 脚本 | 主题 | 命令 |
|------|------|------|
| `01-files.sh` | 文件与目录操作 | pwd, ls, mkdir, touch, cp, mv, rm, find, ln |
| `02-view.sh` | 文件查看与搜索 | cat, head, tail -f, grep, grep -r, less |
| `03-process.sh` | 进程与系统状态 | ps, ss, top, free, df, nohup, kill, du, lsof |

每个脚本可直接运行（`bash 01-files.sh`），演示命令的用法；也可以复制命令逐条手动执行学习。

## 练习步骤

1. `bash scripts/01-files.sh` — 熟悉文件目录操作
2. `bash scripts/02-view.sh` — 熟悉日志查看与搜索
3. `bash scripts/03-process.sh` — 熟悉进程与端口排查
4. 打开 IDEA 按 `git-exercises/README.md` 完成 Git 实操
